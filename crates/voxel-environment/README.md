# voxel-environment

The renderer's shared environment-lighting contract.

This crate owns the CPU description of the sun, day/night state and analytic sky
parameters, plus the WGSL functions that consume the same values. The important
boundary is that the sky seen by a camera and the sky used to illuminate a surface
must be one environment, not two unrelated colour ramps.

The current provider is JolifantoBambla's Hillaire-based LUT path, adapted to Atrium's
world scale. Persistent textures are generated by compute passes and sampled by DDA/CAGI:

- all values are linear RGB radiance-like scene values;
- the sun direction, colour and strength are shared by direct lighting and the visible
  disc;
- physical sky radiance is shared by CAGI, diffuse lighting and finite-distance aerial
  perspective;
- aerial perspective uses a camera-relative froxel grid: screen X/Y reconstruct the
  current DDA ray basis and Z is logarithmic distance between the configured near/far
  bounds;
- the camera backdrop has a separate environment-owned appearance layer (horizon/zenith
  palette, stars, moon and sun disc), so visual styling cannot silently change light transport;
- the atmosphere uses Jolifanto's Earth-like Rayleigh/Mie/ozone parameters and
  Cornette--Shanks phase function;
- transmittance, multiple-scattering, sky-view, and aerial-perspective LUTs use
  Jolifanto's 256×64, 32×32, 192×108, and 32×32×32 starting sizes;
- LUTs regenerate when atmosphere/sun state changes, while camera-dependent view LUTs
  also invalidate on camera changes;
- no display, tone mapping or WebGPU surface policy belongs here.

The provider is based on Hillaire's 2020 Sky Atmosphere technique. The
`JolifantoBambla/webgpu-sky-atmosphere` project supplies the WGSL/WebGPU implementation,
while `sebh/UnrealEngineSkyAtmosphere` remains the reference implementation and
comparison harness. The adapted shader preserves the MIT attribution and the underlying
Bruneton attribution where applicable. Consumers should not need to change when LUT
resolutions or provider implementations evolve.

The provider is adapted to this engine's world scale (`1` voxel world unit is not
necessarily `1` km). Camera misses use the appearance layer near the viewer and blend toward
the aerial-perspective LUT with distance; CAGI remains a pure neighbour-based transport pass
fed by the physical LUT values.
